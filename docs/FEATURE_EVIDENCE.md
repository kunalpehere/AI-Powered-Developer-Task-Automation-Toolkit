# Supported behavior and evidence

Claims here concern file workflows and Phase 6 durable project-review scheduling.
Dynamic plugins remain experimental. Test functions and parametrized
cases are in the linked files; installed checks exercise the built wheel as well.

| Advertised behavior | Regression evidence | Installed evidence |
| --- | --- | --- |
| Inspection counts, extensions, largest files, size filters | [MVP tests](../tests/test_mvp.py): inspection summary, exclusion and human-report tests | Inspection JSON/text, exclusion and deterministic repeat |
| Full SHA-256 duplicates, size filtering, empty files | [MVP tests](../tests/test_mvp.py): candidate selection, equal-size matching-prefix, unique-size, changed/read-failed candidates | Duplicate JSON/text from identical fixture logs |
| Explicit selections and exclusions, portable glob semantics | [MVP tests](../tests/test_mvp.py): parametrized glob cases, pruning, include/all-files, unrelated source preservation | Selected copies, exclusion, invalid glob, selection-required failure |
| Read-only preview and exact-plan application | [Planning tests](../tests/test_planning_execution.py): immutable preview, unchanged database, changed source, plan reused after confirmation | Preview without journal/output, tracked copy and approved move |
| Type/date/size and validated destination templates | [Planning tests](../tests/test_planning_execution.py): placeholders, traversal, reserved paths, overlap and collisions; [MVP tests](../tests/test_mvp.py): exact size boundaries | Size preview and traversal rejection |
| Preserve existing destinations and partial results | [Baseline tests](../tests/test_baseline.py): exclusive creation and destination races; [planning tests](../tests/test_planning_execution.py): partial write, unlink and history failure | Repeat workflow skips and conflict-error preservation |
| Refuse links/reparse points and report access errors | [Planning tests](../tests/test_planning_execution.py): real links/junctions plus injected state/read/write failures; [MVP tests](../tests/test_mvp.py): stat/walk/hash failures | Invalid/missing paths; real OS edge cases remain regression checks |
| Strict version-1 JSON, canonical round trips and path context | [Workflow tests](../tests/test_workflows.py): malformed/duplicate keys, types, versions, immutable config, defaults, home/config-relative paths | Validate and run from a different working directory |
| Stop/continue, sequential dependent steps | [Workflow tests](../tests/test_workflows.py): mixed results, earlier output consumption, preview not simulating outputs | Both policies after a missing-source step |
| UUID run history, legacy migration, journal failure truthfulness | [Workflow tests](../tests/test_workflows.py): start/file/step/final journal failures, interrupted running states, version migration, read-only queries | Run list/show, direct association, file links, unknown/legacy history |
| Useful JSON/text, error exits and diagnostic redaction | [MVP tests](../tests/test_mvp.py): Unicode/CP1252 pipes and JSON errors; [workflow tests](../tests/test_workflows.py): redaction in reports/logs/database | Text/JSON, invalid JSON without source echo, exit 1/2 cases |
| Safe demo and clean packaging | [Baseline tests](../tests/test_baseline.py): module help/disposable demo | Existing sentinel preserved, no database, fixtures removed, both entry points/import origin checked |
| Durable scheduling, retries, dependencies, cancellation and recovery | [Scheduler tests](../tests/test_scheduler.py): due times, restart, cadence, retry budget, blocking/cycles, atomic owner claims, crash review, real process-tree timeout/shutdown, journal failure | Saved review dispatched without original config, attempts, pause/resume/cancel, invalid dependency |

Installed evidence is generated by [verify_install.py](../scripts/verify_install.py)
and saved in [Phase 6 results](audits/phase6-install-results.json). The
[phase record](PHASE_6.md) gives scope and limitations. Distribution and
configuration checks live in [check_dist.py](../scripts/check_dist.py) and
[check_project.py](../scripts/check_project.py).

Read tests alongside [design notes](DESIGN.md). These checks do not establish
hostile-tree isolation, automatic crash replay, performance guarantees, full ACL
fidelity, distributed scheduling, or results on platforms that have not actually run.
